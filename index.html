Description

This is a very simple module to manage Vim. It manages the packages, the .vimrc configuration file and populates a few syntax files for Puppet. This is meant to make vim useful on servers with some basic, sane settings. It is not meant to manage a developer's workstation where you would be managing a ton of plugins and configuration.

Documented with Puppet Strings at http://ghoneycutt.github.io/puppet-module-vim/.

Setup

What vim affects

This module manages the /root/.vimrc file and /root/.vim directory, which gets some plugins installed. It also manages the related vim packages for the platform.

Usage

The normal use case.

include vim

To specify the package list.

class { 'vim':
  package_list => ['vim', 'vim-whatever'],
}

Limitations

This module has been tested to work on the following systems with OpenVox 8 and 9. Please see .github/workflows/ci.yaml for a full matrix of supported versions. This module aims to support the current and previous major OpenVox versions.

  • EL 8
  • EL 9
  • EL 10
  • Debian 13
  • Ubuntu 22.04 LTS
  • Ubuntu 24.04 LTS
  • Ubuntu 26.04 LTS

May work

This module does not fail on unsupported platforms and has been known to work on many, many platforms since its creation in 2010. Solaris is listed in metadata.json without versions: its package data remains in data/ but nothing tests it. Package data for the following platforms also remains in data/ though they are no longer tested or formally supported.

  • EL 5, 6 and 7
  • Debian 12 and older
  • Solaris 10 and 11
  • Suse
  • Ubuntu 20.04 LTS and older
